# Server 侧自绘窗口的模型（2026-10-14）

## 0. 前提

- Server 进程里自绘的窗口都跑在 UI 线程上（普通置顶窗会被商店 / 任务栏搜索这些高 z-band 宿主盖住，
  只有本进程配合 uiAccess 签名才能盖过）。本文**只规定窗口之间的关系**，不管画成什么样。
- 实现落在 `apps/windows/server/src/ui/`：两类窗口各有一个**模板**（见 §5）。

## 1. 两类窗口

按「谁管生命周期」分：

| 类 | 说明 | 现在的例子 |
|---|---|---|
| **独立窗口**（independent window） | 有自己那块窗，也有**自己的生命周期**（UI 线程建、按需显示 / 隐藏、随进程销毁） | 候选窗口、悬浮工具栏、状态切换提示 |
| **辅助窗口**（auxiliary window） | 挂在某块独立窗口上的辅助信息 / 提示窗口；它是那块独立窗口的**资产**（asset） | 候选窗口的「键位映射参考」 |

- 每个辅助窗口**有且只有一个所有者**（owner）—— 它的宿主独立窗口；
- 资产挂在宿主名下的**资产表**里：宿主**先建好自己那块窗，再建资产**；宿主销毁**之前**先把资产放掉。
  资产的寿命就是这段区间。

## 2. 所有权

- 辅助窗口的所有权**在它的生命周期内不发生转移**，也**不会被直接借用** ——
  资产表只有「收进来」与「放掉」，没有「取出来」的口子。
- 这条只管辅助窗口。**独立窗口之间不受它约束**：它们各有自己的生命周期，需要通讯就**直接**通讯。

## 3. 桥接（bridging）

辅助窗口**不能**直接跟其他辅助窗口通讯，也**不能**跟不是它所有者的独立窗口通讯 ——
要几何、要开关、要内容，都得**委托它的所有者**。这条委托路叫**桥接**（bridging）。

- 桥上由**所有者**这一侧实现（实现上是一个 trait），每次驱动资产时把 `&dyn Bridge` **借**给它用一下；
- **借完就还**：借出去的是引用，资产**存不下**它（想留存就得给自己加生命周期参数，一眼看得出违规）；
- 宿主与资产之间**只有**这条桥：宿主驱动资产（`sync` / `hide` / `set_lines`），
  资产经桥向宿主要东西（`host()` / `asset_on()`）。
- 进程级的共用件（共享渲染器、显示器查询那套）不是窗口，不算「通讯对象」。

## 4. 资产克隆与资产窃取

> 本输入法暂时用不上这两条，但先把规则定下来（写死了才好照着实现）。

### 4.1 资产克隆（asset cloning）

独立窗口 **A** 想拿到另一个独立窗口 **B** 的资产 **B1**，要**同时**满足三条：

1. **B1 在生命周期之内**（B 还没把它放掉）；
2. **B1 具备允许克隆的特性** —— 它除了实现「资产」那个 trait，还要额外实现一个**可克隆** trait
   （下称 `Clonable`）；
3. **B 收到来自 A 的克隆请求**（独立窗口之间可以直接通讯，请求走它们自己那条路）。

三条都满足时：

- **A 添加一件 A1**：**除所有者以外**，其余内容与 B1 一样；
- **A1 的所有者是 A**（不复制所有者，也不会是 B）；
- **B1 不受影响**：还归 B，还在 B 的生命周期里。

形状上大致是这样（**尚未实现**，先把语义写死）：

```rust
/// 允许被别的独立窗口克隆的资产额外实现它。
pub(super) trait Clonable: Asset {
    /// 克隆一份「除所有者以外」都一样的自己；克隆件由**请求方**持有、所有者是请求方。
    fn clone_asset(&self) -> Box<dyn Asset>;
}
```

### 4.2 资产窃取（asset stealing）

**A 从 B 克隆 B1 成 A1，且 B1 在克隆之后被立即销毁** —— 这整个过程叫**资产窃取**。

- 之后 A 名下的资产是 **A1**，**不再是 B1**；**B1 已经被抹去**；
- 克隆件是**新的**资产（不是引用、也不是句柄），所以 B1 被销毁不影响 A1，反过来也一样。

## 5. 实现落点

- **独立窗口模板**（`ui/independent_window_template/`）：注册窗口类 + 建一块**分层、置顶、不抢焦点**的弹出窗
  （纯展示的再加 `TRANSPARENT` 让鼠标穿透），并**管名下的资产** —— `Assets` 的 `add` / `sync` / `hide` /
  `set_lines` / `retire`，`Drop` 里**先 `retire` 再 `DestroyWindow` 自己**（§1 的寿命规矩由模板保证）。
- **辅助窗口模板**（`ui/auxiliary_window_template/`）：资产用的那块**分层面板**（主题背景 + 圆角 + 阴影；
  宽 / 高 / 间隙三个属性，没设过按宿主形状算默认；`set_lines` 填几行文字；`show(宿主内容区矩形, 排布方向)`
  贴宿主摆位 —— 宿主右边 / 下边放不下就换左边 / 上边）。
- **资产这层**（`ui/auxiliary/`）：`Asset`（资产）、`Assets`（宿主名下的资产表）、`Bridge`（桥）、
  `Host`（宿主喂给资产的形状：内容区矩形 / 排布方向 / 是不是展开着）。
- 现在只有一件资产：候选窗口的**键位映射参考**（`ui/auxiliary/key_map/`）。
