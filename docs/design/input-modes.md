# v / u / i 模式（2026-10-19）

这三个模式都从中文输入状态进入；`v` 已有表达式，`u` 是符号快速输入，`i` 预留给以后的接口。

## 进入方式

| 输入方案 | 进入方式 |
|---|---|
| 全键拼音 | 组句开始前直接按 `v` / `u` / `i`；`Ctrl+Alt+V` / `U` 也可进入 |
| 双键拼音、形码等非全拼 | `Ctrl + Alt + V` / `U`（TSF 保留键，脚本抢不走）；`I` 只保留入口 |

全拼的 `u` 只有在**空组句**时进 u 模式；已经在组句里（例如 `nu`）仍按普通拼音处理。
`Ctrl+Alt+U` / `V` 由 TSF `PreserveKey` 送到 Server，Server 也只从空组句进入；非全拼的 v 模式
由 `Engine::start_expression` 显式强制表达式前缀，不受双键拼音「`v` 是按键」的影响。
中英混输的英文词仍然从模式前缀开始匹配：`v` 模式打 `very`、u 模式打 `undo`、i 模式打 `input`。

`v` 模式暂不改；以后把表达式 / 快捷候选的接口开放给 Lua 脚本：

> TODO(v 模式)：给脚本提供注册快捷输入前缀 / 计算器的接口，脚本可以往 `v` 模式里加自己的候选，不再只靠 Core 内置的日期、算式和中文数字。

`i` 模式目前只保留入口约定，还没有实现；在实现之前，全拼的 `i` 继续当普通拼音键。

## u 模式：符号快速输入

u 模式有**字母输入**和**符号输入**两种状态：

- 支持中英混输时，进入 u 模式默认是字母输入，不显示符号窗口；按 `Space` 切到符号输入。
- 没有中英混输、或混输开关关着时，进入就是符号输入，不需要按 `Space`。

符号输入时，候选窗口固定显示六类（不带序号前缀）：

1. 常用符号
2. 序号 | 角标
3. 希腊字母
4. 西里尔字母
5. 日文假名
6. 制表符 | 箭头

候选窗口旁边同时挂出「符号输入窗口」：复用候选窗口的辅助窗口资产，位置规则与双键拼音的键位映射参考一样；
最小高度也相同（316 物理像素）。窗口里是四排正方形键格，键位固定：

```text
1234567890-=
QWERTYUIOP[]
ASDFGHJKL;'
ZXCVBNM,./
```

进入时高亮第一类；方向键按候选窗的排布方向移动分类（竖排 `↑` / `↓`，横排 `←` / `→`），符号窗口里的映射跟着高亮分类换。

### 符号窗口开着时的按键

| 按键 | 行为 |
|---|---|
| 符号窗口里有的键（含 `Shift`） | 上屏对应符号，保留 u 模式与符号窗口 |
| `Esc` | 关符号窗口，再关候选窗口（清空本次 u 模式） |
| `Backspace` / `Delete` | 保持应用里的删除行为（删光标左 / 右字符），不当作符号键 |
| 方向键 | 按排布方向切换高亮分类，同时换符号窗口映射 |
| `Space` | 有混输时切回字母输入；没有混输时吞键，不选分类、不上屏 |
| 字母输入里的 `Space` | 仅当拼音串只剩 `u` 时切符号输入；出现其它字母后按普通选词 / 上屏 |
| `Tab` | 日文假名：循环平假名 / 片假名；制表符|箭头：循环映射内容；其它分类不做 |
| 字母键 | 按当前分类的符号表上屏；要输入英文先按 `Space` 回字母输入 |

符号窗口左下角**始终预留一行**：日文假名显示「按下Tab切换平假名/片假名」，
西里尔字母显示「Ё/ё 在前斜杠键」，其它分类留空但保留高度。

### 中英混输

前提是当前输入方案支持中英混输，并且对应开关打开（全拼 `[input] mixture_input`，双键拼音方案文件的 `mixture_input`）。

- 支持混输时，进入 u 模式默认字母输入；`undo` 就是 `u` 进模式后依次打 `n` `d` `o`。
- `Space` 切到符号输入后，字母键按符号表上屏；再按 `Space` 回字母输入继续匹配英文。
- 不支持中英混输时没有字母输入状态，进入就是符号输入，字母直接按符号表上屏。
- 支持混输时，候选窗底部翻译 Tip 的位置：字母输入显示「按空格进入符号输入」，符号输入显示「按空格退出符号输入」；没有混输时不显示提示。

### 符号表

六个分类的映射在 `apps/windows/server/src/dispatch/u_mode/mapping.rs` 的 `SymbolEntry` 表里。
每个键写正常按下与 `Shift` 两套符号；没有上档的键只写正常符号，Shift 按下时不输出。
符号窗口里正常符号画在格子下方居中、Shift 符号画在上方居中。

希腊字母的 `;` 是重音状态开关，`'` 是隔音状态开关；两种状态同时打开时只保留 `i` / `y` 的 `ΐ` / `ΰ`。
西里尔字母的 `Ё/ё` 放在前斜杠键，符号窗口左下角显示备注；日文假名按 Tab 切平假名 / 片假名，
制表符|箭头按 Tab 切两套映射。

### 实现落点

- 进入 / 按键 / 分类状态：`apps/windows/server/src/dispatch/u_mode/`、`dispatch/key/input.rs`
- 候选列表与 Tip：`dispatch/composed/mod.rs`
- 符号窗口：复用 `ui/auxiliary` 的键位映射资产，新增临时符号模式（不影响用户配置的键位映射参考）
- 非全拼入口：`InputSettings::full_pinyin` + TSF 的 `GUID_MODE_U`

## 与脚本的关系

输入法自己占用的组合键（包括预留给 v/u/i 的 `Ctrl+Alt+V/U/I`）不派发给脚本；
脚本清单里声明它们会判无效。符号表属于输入法内置数据，暂不开放给 Lua。
