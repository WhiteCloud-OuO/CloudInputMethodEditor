## 切换模式与输入状态

| 操作 | 按键 |
|---|---|
| 中 / 英切换 | 单击 `Shift`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 直接输入大写英文 | `Caps Lock` 亮起（只控制大小写，不改中 / 英状态；熄灭后回到原来的中 / 英） |
| 大写锁定亮着时切英文 | 单击 `Shift`：取消大写锁定并切到英文（与微软拼音一致） |
| 禁用 / 启用输入法 | `Ctrl + Space`（系统的「输入法 / 非输入法切换」）：禁用后所有按键原样交给应用，悬浮状态栏收起，任务栏图标显示「禁」；重新启用回到禁用前的中 / 英 |
| 切换全角 / 半角字符 | `Shift + Space`；或点击悬浮状态条上的「全角 / 半角」按钮：直通给应用的字母、数字与符号转全角，中英两模式都算、重启回缺省 |
| 切换中文 / 西文标点 | `Ctrl + Alt + ,`；或点击悬浮状态条上的「中文标点 / 英文标点」按钮，中英各记一份、重启回缺省 |
| 切换简 / 繁输出 | `Ctrl + Alt + .`；或点击悬浮状态条上的「简 / 繁」按钮，与「设置 → 输入」里的「简体中文 / 繁體中文切换」同一个开关（写回配置） |
| 输入拼音时输入大写字母 | `Shift + 字母`：固定收进组句，大写按小写参与匹配，`Cpan` 与 `cpan` 一样能出「C盘」；原样上屏时还原大写 |
| 切换到其他输入法 | `Win + Space`（系统） |

中 / 英切换固定用**单击 Shift**（与微软拼音一致）；没在打字时 Shift 在其他组合键里的作用不受影响。中英模式所有应用共用一份。

`Ctrl + Space` 是**禁用 / 启用**输入法（不是切英文）：禁用时完全不接管，按键原样交给应用，悬浮状态栏收起，任务栏图标换成「禁」。它与中 / 英是两个维度，重新启用回到禁用前的中 / 英。

`Shift + Space`、`Ctrl + Alt + ,`、`Ctrl + Alt + .` 是固定内置热键，不提供改键；后两个走 TSF 保留键，在应用自己的快捷键之前被输入法接走。

Windows 的主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

英文模式的进入方式与行为见 [英文模式](../input/english-mode.md)。

## 输入组句时（拼音）

| 操作 | 按键 |
|---|---|
| 选上高亮候选并进组句（无候选时上屏所敲的拼音） | `Space` |
| 选上当前页第 N 个并进组句 | `1` 至 `9` |
| 上屏用户短语 / 整句，或杀掉一个词 | `Ctrl + 1` 至 `Ctrl + 9` |
| 选上高亮候选、剩余拼音补完整体上屏，再上屏这个标点 | 拼音后敲标点（`,` `.` `?` 等；`-` `=` 是翻页键，`_` `+` 与 `'` 除外） |
| 将已选文本与剩余拼音原样上屏（去掉拼音分隔符 `'`） | `Enter` |
| 原样上屏并记一次（同一串记够两次收进自造词库，作为英文词） | `Ctrl + Enter` |
| 轮换英文候选的大小写（有英文候选时） | `` ` ``（主键盘 `1` 左侧） |
| 撤回上一次选择（有已选文本且光标在拼音末尾时）；否则删光标前一个字母 | `Backspace` |
| 只上屏已选的文本，未选的拼音直接丢弃（`云朵shurufa` → 上屏 `云朵`） | `Insert` |
| 清空（已选文本也不落文档） | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` |
| 翻页 | `-` `=`（主键盘）、`PageUp` / `PageDown`、`Tab`（下一页）/ `Shift + Tab`（上一页） |
| 移动拼音光标 | `←` / `→` |
| 光标移到开头 / 末尾 | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；选上后其余拼音保留，光标移到末尾。光标只落在未选拼音范围内，移动与删除都不会进到已选文本里。

翻页键固定用主键盘的 `-`（上一页）与 `=`（下一页），不可修改。

`Ctrl + 数字` 按那一格的来源分三种：**用户短语**直接上屏（和敲它的序号一样）；**整句候选**先记一次再上屏——同一整句记够两次就收进用户自造词库，之后它按词出；**中文 / 英文词**是**杀词**：自造词从用户词库删掉（下次不再出），词库已有的词清掉对它的学习、权重回到初始，随后候选立即重排。
这一页没有那一格（候选不够）时，这个组合仍交给应用。

`Ctrl`（或 `Alt` / `Win`）加其他键一律交给应用，输入法不接管；只有组句时的 `Ctrl + 数字` 例外。

## 英文模式下

英文模式是**纯直通**：字母、数字、标点、空格、回车全部直接交给应用，不出现候选窗口、不组句，
与没装输入法时一致（终端与代码编辑器里的补全、`Tab`、方向键不会被占掉）。
要英文词的补全与拼错纠正请切回中文模式，见 [英文模式](../input/english-mode.md) 与 [快捷输入](../input/shortcuts.md)。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字与金额（`v123.5` → 壹佰贰拾叁元伍角） |

详见 [快捷输入](../input/shortcuts.md)。表达式前缀固定为 `v`，不可修改。
