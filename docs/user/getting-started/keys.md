## 切换模式与输入状态

| 操作 | 按键 |
|---|---|
| 中 / 英切换 | 单击 `Shift`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 直接输入大写英文 | `Caps Lock` 亮起（只控制大小写，不改中 / 英状态；熄灭后回到原来的中 / 英） |
| 大写锁定亮着时切英文 | 单击 `Shift`：取消大写锁定并切到英文（与微软拼音一致） |
| 禁用 / 启用输入法 | `Ctrl + Space`（系统的「输入法 / 非输入法切换」）：禁用后所有按键原样交给应用，悬浮状态栏收起，任务栏图标显示「禁」；重新启用回到禁用前的中 / 英 |
| 切换全角 / 半角字符 | `Shift + Space`；或点击悬浮状态条上的「全角 / 半角」按钮：直通给应用的字母、数字与符号转全角，中英两模式都算、重启回缺省 |
| 切换中文 / 西文标点 | `Ctrl + Alt + ,`；或点击悬浮状态条上的「中文标点 / 英文标点」按钮，中英各记一份、重启回缺省 |
| 切换简 / 繁输出 | `Ctrl + Alt + .`；或点击悬浮状态条上的「简 / 繁」按钮，与「设置 → 输入」里的「简体中文 / 繁體中文切换」同一个开关（写回配置） |
| 输入拼音时输入大写字母 | `Shift + 字母`：固定收进组句，大写按小写参与匹配，`Cpan` 与 `cpan` 一样能出「C盘」；原样上屏时还原大写 |
| 切换到其他输入法 | `Win + Space`（系统） |

中 / 英切换固定用**单击 Shift**（与微软拼音一致）；没在打字时 Shift 在其他组合键里的作用不受影响。中英模式所有应用共用一份。

`Ctrl + Space` 是**禁用 / 启用**输入法（不是切英文）：禁用时完全不接管，按键原样交给应用，悬浮状态栏收起，任务栏图标换成「禁」。它与中 / 英是两个维度，重新启用回到禁用前的中 / 英。

`Shift + Space`、`Ctrl + Alt + ,`、`Ctrl + Alt + .` 是固定内置热键，不提供改键；后两个走 TSF 保留键，在应用自己的快捷键之前被输入法接走。

Windows 的主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

英文模式的进入方式与行为见 [英文模式](../input/english-mode.md)。

## 输入组句时（拼音）

| 操作 | 按键 |
|---|---|
| 选上高亮候选并进组句（无候选时上屏所敲的拼音） | `Space` |
| 选上当前页第 N 个并进组句 | `1` 至 `9` |
| 上屏用户短语 / 整句，或杀掉一个词 | `Ctrl + 1` 至 `Ctrl + 9` |
| 选上高亮候选、剩余拼音补完整体上屏，再上屏这个标点 | 拼音后敲标点（`,` `.` `?` 等；`-` `=` 是翻页键，`_` `+` 与 `'` 除外） |
| 将已选文本与剩余拼音原样上屏（去掉拼音分隔符 `'`） | `Enter` |
| 在拼音串里插一颗分隔符，强制在这里分音节（`xi'an` 不按 `xian` 切） | `'` |
| 原样上屏并记一次（同一串记够两次收进自造词库，作为英文词） | `Ctrl + Enter` |
| 轮换英文候选的大小写（有英文候选时） | `` ` ``（主键盘 `1` 左侧） |
| 撤回上一次选择（有已选文本且光标在拼音末尾时）；否则删光标前一个字母 | `Backspace` |
| 只上屏已选的文本，未选的拼音直接丢弃（`云朵shurufa` → 上屏 `云朵`） | `Insert` |
| 上屏翻译 Tip 的译文（有译文时）；底部那一行的**在线译文**也算一条（它在列表里排第一） | Ctrl + 反引号 |
| 朗读翻译 Tip 的译文（有译文时） | Shift + 反引号 |
| 清空（已选文本也不落文档） | `Esc` |
| 移动高亮 | 沿列表方向：竖排 `↑` / `↓`、横排 `←` / `→`；展开成网格后四个方向都移高亮 |
| 翻页 | `-` `=`（主键盘）、`PageUp` / `PageDown`；**收起时另一个轴**也翻页（竖排 `←` / `→`、横排 `↑` / `↓`） |
| 展开 / 收起「更多候选项」 | `Tab` |
| 移动拼音光标 | `[` / `]`（收起与展开都一样；不组句时 `[` 仍是 `【`） |
| 光标移到开头 / 末尾 | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；选上后其余拼音保留，光标移到末尾。光标只落在未选拼音范围内，移动与删除都不会进到已选文本里。

翻页键固定用主键盘的 `-`（上一页）与 `=`（下一页），不可修改。

`'` 只当分隔符、自己不进候选：它把前后切成两个音节（`xi'an` 出「西安」而不是「先」，`fan'gan` 与 `fang'an` 也是两条）。敲下去**立刻**看得见 —— 末尾那颗也一样（后面还没敲字母时也显示），连着敲两颗只显示一颗。

候选窗**底部那一行**左侧是**翻译 Tip**：高亮候选在本地词典里的释义（词典与开关在「设置 → 翻译」里选，见 [设置](../settings/preferences.md#翻译)）。按 `Ctrl + 反引号` 就把这条译文上屏，拼音照那个候选消耗；一个候选有多条释义时，候选窗会先变成释义列表（顶部一行是被翻译的词条、下面每行 `① sad (adj.)`，**没有页码**、展开态下临时收回单列 / 单行）：高亮条跟着鼠标走、点一下选它，也可以按方向键挪高亮、**空格**选高亮那条、按数字直接选第几条，`Esc` 退出。同一个词条的译文上屏够「学会所需上屏次数」次之后，Tip 的颜色会从橙色变成深灰。

按 `Shift + 反引号` 让系统**念**译文（单词发音）：只有一条释义时直接念；多条释义要先用 `Ctrl + 反引号` 进释义列表，进去之后这一键念**高亮那条**（用方向键挪、再按一次念）。没有译文时这一键不做事。开着翻译 Tip 且正在组句时 `Shift + 反引号` 被发音占用，**不再输入 `~`**；没在组句时它照旧是 `~`。

候选窗**底部再下面一行**是在线翻译，**它现在由脚本决定**（没有一个内置的热键）：脚本自己绑键（`Ctrl + T` 之类）、自己调厂商接口、把结果写在这一行。**这一行可以有好几行**（脚本在文本里写换行就行，示例里长译文会按候选窗当前宽度自动折行、最多 5 行）。安装目录的 `Scripts\lib\example-niutrans.lua` 是一份能直接抄的完整示例（拷到 `Scripts\` 下、填上 appId / apikey、重启输入法服务就生效）。

这一行**也参与 `Ctrl + 反引号`**：按下去时它跟本地词典的释义一起列出来、**排在最前面**（列表里标着 `(在线)`）——只有它一条就直接上屏；一条本地释义加一条在线译文会进释义选择；那一行不是给当前高亮候选写的（比如你已经挪过候选）就不算数。

### 鼠标

候选窗出现后，鼠标移到哪个候选上，**高亮就跟到哪**（收起、展开都一样）；点一下那一格直接上屏（上屏要等下一拍轮询把文本取回，最多约 80 ms）。这样选中的候选，接着编辑拼音也不会被跳回第 1 格——高亮钉在鼠标那一格，鼠标移开候选窗才恢复「编辑拼音就回到第 1 格」。

**右键**单击候选等于按一下 `Ctrl + 反引号`：上屏它的译文，多条释义时先进选择界面（数字键选、`Esc` 退出）；「设置 → 翻译 → 启用翻译 Tip」关着时右键不响应。**在释义选择界面里，右键点窗口的任何位置都等于 `Esc`**（取消选择）。

**中键**单击候选等于按一下 `Shift + 反引号`：**念**译文（发音）——只有一条释义直接念，多条要先 `Ctrl + 反引号` 进释义列表、进去之后中键念高亮那条；点在哪一格都一样，念的是高亮那个。没有译文时不响。「启用翻译 Tip」关着时中键也不响应。

**滚轮**：不带修饰键时翻页——**下滚下一页、上滚上一页**；展开「更多候选项」时一页就是一整屏。翻页只换内容，**高亮条留在窗口的同一格**（原来在第 3 格，翻完还在第 3 格；键盘翻页仍是落到新页第一个）。按着 **`Ctrl`** 滚轮则是**临时缩放整个候选窗**（框、留白、文字一起变）：下滚每格 ×1.2（1.2 倍 → 1.44 倍 → 1.73 倍……），上滚缩小，范围约 58%–299%；缩小了再滚回来能精确回到 100%。缩放只在内存里，**候选窗一关就回到 100%**（Server 重启亦然）。

### 更多候选项

组句时按 `Tab` 把候选窗展开成**一整屏**：竖排变成 5 列、横排变成 5 行，另一个方向由「设置 → 候选 → 候选项个数」定（设成 7 就是 5 列 7 行，一屏 35 个候选）。**展开时有约 0.3 秒的过渡**（框从原来大小长到一整屏、内容淡入）；收起是立即生效，没有过渡。展开后：

- 序号不再显示，候选按权重**从左到右、从上到下**铺开一屏；这一屏就是「一页」，`-` `=` / `PageUp` / `PageDown` 按屏翻。
- 所有格子都和**收起时那条高亮圆角矩形**一样宽：更长的候选截尾加「…」，短的照原样留着（单字候选也不会挤成一小团）。展开后每格还有一个下限：**横排**是「6 个候选字宽 + 角标宽度」；**竖排**是「这一屏最长的候选 + 2 个候选字宽 + 一个角标字宽」（竖排这条不管这一屏有没有角标都算进去）。每格还有一个**上限**：「设置 → 候选 → 展开后每个候选项的最大宽度」（缺省 420 像素，`0` 表示不限）——超过它的候选截尾加「…」，所以特别长的候选不会再让整屏格子一起变宽。角标在格子里一律**贴右边缘**（往里让一点）；**收起**的横排里，候选词与角标之间则至少隔两个候选字宽（竖排收起时角标在自己的列里，仍是原样）。
- 数字键改成**跳到第几页**：`1`–`9` 是第 1–9 页、`0` 是第 10 页（没有那么多页就落到最后一页）；`Ctrl + 数字` 这时不杀词，仍交给应用。
- 方向键在格子里移高亮（`←` `→` 也移高亮），拼音光标改用 `[` / `]` 移。

再按一次 `Tab` 收起，回到一列（竖排）/ 一行（横排）。每段组句都从收起的样子开始：上屏、清空或失焦之后再打一段拼音，都要重新按 `Tab`。
「设置 → 候选 → 展示更多候选项」关掉后，`Tab` 不再展开（这一键仍由输入法吃掉、不落到文档里）。

`Ctrl + 数字` 按那一格的来源分三种：**用户短语**直接上屏（和敲它的序号一样）；**整句候选**先记一次再上屏——同一整句记够两次就收进用户自造词库，之后它按词出；**中文 / 英文词**是**杀词**：自造词从用户词库删掉（下次不再出），词库已有的词清掉对它的学习、权重回到初始，随后候选立即重排。
这一页没有那一格（候选不够）时，这个组合仍交给应用。

组句内外，带 `Ctrl`（不带 `Alt` / `Win`）的组合都会**先问一趟输入法服务**：脚本可以接管任意 `Ctrl` 组合
（`Ctrl+字母`、`Ctrl+Shift+…` 都行）；没人接管就照旧交给应用。`Alt` / `Win` 组合输入法不碰（那些是系统 / 外壳的键，本来就到不了输入法）。
**输入法自己的那几个组合键脚本抢不走**：`Ctrl+数字`、`Ctrl+回车`、`Ctrl+反引号`、`Shift+反引号` 一律按输入法自己的用法走（杀词 / 原样上屏 / 翻译上屏 / 发音）。

## 英文模式下

英文模式是**纯直通**：字母、数字、标点、空格、回车全部直接交给应用，不出现候选窗口、不组句，
与没装输入法时一致（终端与代码编辑器里的补全、`Tab`、方向键不会被占掉）。
要英文词的补全与拼错纠正请切回中文模式，见 [英文模式](../input/english-mode.md) 与 [快捷输入](../input/shortcuts.md)。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字与金额（`v123.5` → 壹佰贰拾叁元伍角） |

详见 [快捷输入](../input/shortcuts.md)。表达式前缀固定为 `v`，不可修改；敲 `v` 之后按 `Tab` 是表达式计算器（按 `Tab` / `Esc` 退出）。
