## 中英切换

单击 `Shift`（按下即松开，不与其他键组合），任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」；点击该图标同样可以切换。
`Caps Lock` 只控制大小写，熄灭后回到原来的中 / 英；亮着时单击 `Shift` 会取消大写锁定并切到英文。
按 `Ctrl + Space` 是禁用 / 启用输入法（不是切中英）：禁用后按键原样交给应用、悬浮状态栏收起、任务栏图标变「禁」。

英文模式下的行为见 [英文模式](../input/english-mode.md)。

## 候选窗口

输入拼音时，候选窗口显示在光标下方：顶部一行是已输入的拼音（自动按音节分隔），其下是候选，右下角是页码。缺省竖排，每页 9 个，均可在设置中修改。
候选右侧偶有一个浅灰小字标明它的来源：「短」是用「设置 → 短语」加的自定义短语，「句」是整句候选，「造」是你自己造出来、已记进用户词库的词；其余候选没有。
整句候选按 `Ctrl + 数字` 会上屏并记一次，同一整句记够两次就变成自造词。

## 整句输入

无需切换模式，连续输入整句后再上屏：`jintiantianqihenhao` 的首选即为「今天天气很好」。简拼同样可用：`jttqhh`。
两三个字母的简拼通常仍按词处理（`sj` 时间），需要整句时请多输入几个音节。
不要简拼（只认完整音节）可以在「设置 → 输入」里关掉「使用简拼」。

## 常用按键

| 操作 | 按键 |
|---|---|
| 上屏首选（或高亮候选） | `Space` |
| 上屏第 N 个候选 | 数字 `1` 至 `9` |
| 将拼音字母原样上屏 | `Enter` |
| 翻页 | `-` `=`（主键盘），或 `PageUp` / `PageDown` |
| 移动高亮 | `↑` / `↓` |
| 删除一个字母 | `Backspace` |
| 清空 | `Esc` |

完整按键表见 [按键与快捷键](keys.md)。

## 中文标点

未输入拼音时，中文模式下输入 `, . ? ! : ; ( ) [ ] < > \ ^ _ $ ~` 得到全角标点，`"` `'` 成对切换；数字之后的 `.` 保持半角（`3.14`）。
拼音打完后直接敲标点，会**先把当前高亮的候选上屏、再上屏这个标点**：`bairiyishanjin` 出 白日依山尽 后敲 `,` → 白日依山尽，。
`-` `=` 是翻页键；它们上档的 `_` `+` 与拼音分隔符 `'` 不触发上屏，仍按原来的方式进输入缓冲。

Windows 上全角转换随时可切：点击悬浮状态条上的「中文标点 / 英文标点」按钮，关了出半角、开了出全角，切的是当前模式那份（中英各记一份，缺省中文全角、英文半角，切换模式时随之切换；状态只记到本次运行，重启后回缺省）。英文模式需要全角时，在英文状态下点该按钮即可。任务栏「中 / 英」图标的右键菜单里也有「全角标点」一项，效果相同。

「全角 / 半角」按钮管的是另一件事：直通给应用的字母、数字与符号整体转全角（`abc` → `ａｂｃ`），中英两模式都算，中文标点仍按上面那份设置走。缺省半角。

## 选错了词

上屏后用 `Backspace` 删除，再输入同一段拼音改选其他候选，上一次记录的学习会被撤销；误按 `Space` 选中错词不会被输入法记住。
连续删除后面几个词再从头重输同样有效：删除「沃德书」后重输为「我的书」，「沃德」那次选择视为未发生。

一段拼音分几次选完（先选一个字，剩余部分整句上屏），第二次以同样方式输入时，合起来的词会被记为用户词；连续选出的两个词合起来词库里没有时也同理（同一段或分两段打，都是连着两次）。此后整段输入时它就排在前面，重复输入越多权重越高。

某个候选排在不想让它靠前的位置时，按 `Ctrl + 数字` 把它**杀掉**：自造词整个从用户词库删掉，词库已有的词清掉对它的学习、回到词库原本的词频，候选立即重排。详见 [按键](../getting-started/keys.md)。
