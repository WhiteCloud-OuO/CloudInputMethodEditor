## 打开

点击悬浮状态条的「工具」，选择「组字查字」。窗口独立运行，关闭它不影响输入法。
窗口配色跟随输入法当前主题；打开时画布默认是左右结构（`LR`），已有两个空槽。

## 画布

窗口上方的结构按钮把当前槽拆成子槽。画布显示为嵌套的方框：

- 单击一个方框选中它，当前槽的边框变为强调色；
- 点结构按钮后，选中的槽按该结构拆分，光标移到第一个空槽；
- 在「部件输入」框中输入或粘贴一个部件，点「填入」（或按回车）写入当前槽，光标自动移到下一个空槽；
- 「？」写入通配符，表示该位置的部件任意；
- 「退格」清空当前槽；当前槽是结构时，整个结构折掉；已经是空槽时退回上一层；
- 「清空」重置整个画布。

画布下方的表达式行显示当前结构对应的 IDS。表达式不完整时，该行给出原因（例如「还有空槽没填完」）。

## 结构缩写

不方便输入结构符号时，可在部件输入框中直接写两字母缩写，或粘贴完整表达式：

| 缩写 | 结构 | 缩写 | 结构 |
|---|---|---|---|
| `LR` | ⿰ 左右 | `LL` | ⿲ 左中右 |
| `UD` | ⿱ 上下 | `UU` | ⿳ 上中下 |
| `OC` | ⿴ 全包围 | `OD` | ⿵ 上包围 |
| `OU` | ⿶ 下包围 | `OR` | ⿷ 左包围 |
| `RD` | ⿸ 左上包围 | `RU` | ⿺ 左下包围 |
| `LD` | ⿹ 右上包围 | `LU` | ⿽ 右下包围 |
| `OL` | ⿼ 右包围 | `XX` | ⿻ 重叠 |
| `MI` | ⿾ 水平镜像 | `RO` | ⿿ 旋转 |
| `SU` | ㇯ 减除 | | |

例如在部件输入框中粘贴 `LR木木`，点「填入」后再点「查询」，结果为「林」。

## 查询与结果

点「查询」或按回车。含「？」的表达式执行通配查询，最多列出 200 条，并显示命中总数。
结果行包含字、码位、命中的 IDS 与来源。双击结果把该字复制到剪贴板。

生僻字可能因系统字体缺字形而显示为方块。将鼠标停在结果行上，右侧会弹出结构示意图：该字的 IDS 被画成嵌套方框，
缺字形的部件显示结构缩写，未编码部件显示为 `{n}`。结果仍可正常复制。

输入框右侧的「替换」按钮打开后，查询前会把常见部件换成 IDS 里的规范写法，例如把「水」当作「氵」、
「手」当作「扌」、「火」当作「灬」。打开时按钮高亮，状态行会注明本次结果「已按常见部件替换」。
再次点击关闭，恢复严格匹配。

## 难输入部件

点工具栏末尾的「部件」打开右侧抽屉。抽屉有四个标签：

- **笔画**：按 1 至 13+ 画分组，另有「未」表示笔画未知；
- **分类**：按「圍 / 頭 / 旁 / 底 / 其它」筛选，标签上的数字为该分类的部件数；
- **收藏**：已星标收藏的部件，重启后仍保留；
- **最近**：最近插入过的 12 个部件。

抽屉顶部的搜索框可输入部件本身、码位十六进制（如 `2008E`）或 IDS 片段 / 运算符缩写（如 `LR`）过滤当前页。

单击部件即写入当前槽，光标自动移到下一个空槽。鼠标停在部件上时，底部显示字符、码位、笔画与位置分类，
右侧的星标按钮用于收藏 / 取消收藏；收藏也可以直接在「收藏」标签中查看。

系统字体缺字形的部件显示该部件结构的缩写（例如 `UD丿口`），右下角有一个小点作提示。

「能用拼音打出」的部件默认不列出；需要查看时点抽屉底部的「显示可打出部件」。

## 更换字体

若希望生僻部件显示为正常字形，可安装覆盖扩展区的字体，并在配置文件 `ids.toml` 中把 `[font] family` 改为该字体名称（文件位置见[数据与日志](../help/data-and-logs.md)）。字体未覆盖的字符仍会退化为结构缩写。
