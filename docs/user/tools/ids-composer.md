## 打开

点击悬浮状态条的「工具」，选择「组字工具」。窗口独立运行，关闭它不影响输入法。
窗口配色跟随输入法当前主题；打开时画布默认是左右结构（`LR`），已有两个空槽。

## 画布

窗口上方的结构按钮把当前槽拆成子槽。画布显示为嵌套的方框：

- 单击一个方框选中它，当前槽的边框变为强调色，同时焦点回到部件输入框；
- 点结构按钮后，选中的槽按该结构拆分，光标移到第一个空槽；
- 在「部件输入」框中输入一个汉字，内容变化时自动写入当前槽，光标自动移到下一个空槽；
- 「？」写入通配符，表示该位置的部件任意；
- 「退格」清空当前槽；当前槽是结构时，整个结构折掉；已经是空槽时退回上一层；
- 「清空」重置整个画布。

画布下方的表达式行显示当前结构对应的 IDS。表达式不完整时，该行给出原因（例如「还有空槽没填完」）。

## 结构按钮

结构按钮直接显示中文结构名（例如「⿰ 左右结构」「⿱ 上下结构」），按名称选择即可；
查询与数据匹配仍使用标准 IDS，不需要手动输入运算符。

## 查询与结果

点「查询」或按回车。含「？」的表达式执行通配查询，最多列出 200 条，并显示命中总数。
结果行包含字、码位、命中的 IDS 与来源。双击结果把该字复制到剪贴板。

生僻字可能因系统字体缺字形而显示为方块，结果仍可正常复制。

## 难输入部件

点工具栏末尾的「部件」打开右侧抽屉。抽屉有三个标签：

- **笔画**：按 1 至 13+ 画分组，另有「未」表示笔画未知；
- **分类**：按「围 / 头 / 旁 / 底 / 其它」筛选，标签上的数字为该分类的部件数；
- **最近**：最近插入过的 12 个部件。

抽屉顶部的搜索框可输入部件本身、码位十六进制（如 `2008E`）或 IDS 片段 / 运算符缩写（如 `LR`）过滤当前页。

单击部件即写入当前槽，光标自动移到下一个空槽。鼠标停在部件上时，底部显示字符、码位、笔画与位置分类。

系统字体缺字形的部件优先显示内置 SVG 字形；没有内置字形时显示码位（如 `U+20087`），
不再出现结构缩写。

「能用拼音打出」的部件默认不列出；需要查看时点抽屉底部的「显示可打出部件」。

## 更换字体

若希望生僻部件显示为正常字形，可安装覆盖扩展区的字体，并在配置文件 `ids.toml` 中把 `[font] family` 改为该字体名称（文件位置见[数据与日志](../help/data-and-logs.md)）。字体与内置 SVG 都未覆盖的字符显示码位。
