## 打开

点击悬浮状态条的「特殊字符」按钮。窗口独立运行、默认置顶，关闭它不影响输入法。
外观跟随输入法当前主题。

## 输入字符

窗口顶部 7 个标签页：常用符号、序号 / 角标、希腊字母、西里尔字母、日文假名、制表符 / 箭头、英文花体。

前 6 页共有 546 个符号按钮：

- **左键**：把字符以模拟键盘输入的方式送到你刚才打字的程序里；
- **右键**：把字符复制到剪贴板，再手动粘贴；
- 鼠标停在符号上，底部会显示它的码位（例如 `± · U+00B1`）。

日文假名页右侧有「无 / 浊゛ / 半゜」三个开关，用来切换假名变体：

- 「浊゛」：只显示能加浊点的假名（う 行、か / さ / た / は 行，平假名与片假名），
  按钮上的字同时换成浊音写法（`か` 显示为 `が`、`う` 显示为 `ゔ`）；
- 「半゜」：只显示は行 / ハ行，按钮换成半浊音写法（`は` 显示为 `ぱ`）；
- 「无」：恢复完整五十音图，按原样输入。

这三个是模式开关，不会把「浊゛」「半゜」当字符打出去。

窗口默认**不抢焦点**：点符号时键盘焦点仍留在目标程序里，可以连续点、连续输入。
如果焦点已经被切到本工具（例如从「英文花体」页切回来），下一次点符号会自动切回上一个目标程序再输入。

## 英文花体

第 7 页把 A–Z / a–z 换成 Unicode 数学字母 / 花体字母：

1. 在「输入英文文本」里输入或粘贴文字（切到这一页时窗口会正常激活并聚焦输入框）；
2. 选一种字母样式（按钮上的样例是「A + 小写 b、c」）：⒜⒝⒞、🅐🅑🅒、🅰🅱🅲、ᴀʙᴄ、
   Ⓐⓑⓒ、🄰🄱🄲、𝔄𝔟𝔠、𝒜𝒷𝒸、𝓐𝓫𝓬、𝕬𝖇𝖈、𝐀𝐛𝐜、𝔸𝕓𝕔、𝐴𝑏𝑐、𝑨𝒃𝒄；
3. 「结果」里实时显示转换后的文字；点「复制结果」复制到剪贴板（结果框只用来查看，
   不能手动选中，复制请用按钮）。

只转换英文字母，数字、空格、标点与中文原样保留。目标程序字体缺字时可能显示成方框，但复制出来的码点是正确的。

## 已知限制

- 目标程序以管理员身份运行时，普通权限的本工具无法向它注入按键（Windows 的 UIPI 限制）；
  用「右键复制」再粘贴即可。
- 少数使用底层键盘钩子 / 独占输入的程序可能收不到模拟输入，同样改用右键复制。
