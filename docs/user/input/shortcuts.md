## V 模式：日期、时间、算式、车牌、取名

日期、时间、星期、现在都在 **V 模式**里：先敲 `v`，候选窗口旁边会出现 V 模式说明；再输入下面的码。

| 输入 | 结果 |
|---|---|
| `vrq` | 日期 12 种写法：`2026年5月4日`、`2026-5-4`、`2026/05/04`、`5月4日`、`5-4`、`5/04` 等 |
| `vsj` | 当前时间 8 种写法：`14时08分`、`下午2时08分`、`14:08`、`14-08`、`2:08 p.m.`、`2-08 p.m.`、`2:08 pm`、`2-08 pm` |
| `vxq` | 星期：`星期一` / `周一` / `礼拜一`；星期日用 `星期日` / `周日` / `礼拜天` |
| `vxz` | 现在：日期 + 时间共 14 种组合写法 |
| `v1+2` | 算式：出 `3` 与 `1+2=3` |
| `v123` | 中文数字：一百二十三 与 壹佰贰拾叁；金额：一百二十三元整 与 壹佰贰拾叁元整 |
| `v123.5` | 小数读法：一百二十三点五 与 壹佰贰拾叁点伍；金额：一百二十三元五角 与 壹佰贰拾叁元伍角（小数最多两位，到分） |
| `v#zhangwei` | 取名：张伟、张卫…（姓先按《姓氏大全》的排名，同一姓氏下按《名字大全》的顺序；单字名与双字名都会出） |

**普通输入里的 `rq` / `sj` / `xq` 不再出日期 / 时间 / 星期候选**，它们只是普通拼音。
V 模式的时间 / 现在是否带秒由「设置 → 输入 → V 模式的时间显示秒数」控制（缺省关）；
打开后 `vsj` 的 8 条与 `vxz` 的 14 条都会加上秒，如 `14:08:36`、`下午2时08分36秒`。

只有**数学表达式与数字转换**里，数字与运算符才进入算式、不能选词；日期、时间、星期、现在、车牌、取名这些快捷候选
都能用数字键（主键盘和小键盘）选中。任何 V 模式候选项也可以用 `↑` / `↓` 加 `Space` 选，`Enter` 将所敲内容原样输出。
以 `v` 开头的英文词（`very`）不受影响，仍给出英文候选。V 模式不再往翻译 Tip 里写提示。

**车牌**：`v@` + 省份简称拼音 + 字母（忽略大小写），例如 `v@sua` → `苏A` / `江苏省南京市` / `江苏南京`。
只输入前几个字母时按前缀列出多条（最多 12 个车牌）；数据来自安装目录 `data\plates.qj`。

**取名**：`v#` + 姓拼音 + 名拼音连写，例如 `v#zhangwei` → `张伟` / `张卫`…；`v#ouyangna` → `欧阳娜`。
姓氏与名字来自安装目录 `data\姓氏大全.tsv` / `data\名字大全.tsv`；姓氏表第 3 列是排名（越小越靠前），
表里没有的稀有姓氏 / 名字字会用软件自带的词库按词频兜底。
只敲到姓氏（`v#wang`）时先出 `王` / `汪` 这些姓氏候选；选中姓氏后它**留在组句里**（显示成 `v#王`），
可以接着敲名的拼音或直接从候选里挑名字，选到完整姓名才上屏。数字键（含小键盘）在这里都能选候选。

`v` 是固定的表达式前缀（`v` 不作为任何拼音音节的开头），不可修改。

### 表达式计算器（只输入 `v` 时按 `Tab`）

只输入一个 `v` 时按 `Tab` 进高级数学计算界面；已经有算式（`v1+2`）时 `Tab` 不进入：

- **拼音那一行显示算式本身**（没有 `v`），**候选固定成结果**（刚进来是 `0`；`=>` 进制转换给三条）。
  候选只有一条时高亮条挪不动（鼠标、方向键都没有第二个目标）。
- 候选窗口旁会挂出「高级数学计算界面」说明窗口：标题、支持的函数列表、底部红色提示「按Tab/Esc退出高级数学计算」。
  **`Tab` 或 `Esc` 退出**，回到 `v` 模式；退出后算式还留着，但只有清回单独的 `v` 才能再按 `Tab` 进入。
- 面板里**不画候选项序号**（只有一条「结果」，编号没意义）；`[` / `]` 仍旧移拼音光标（不进算式），
  **`Delete` 清空算式与结果**（结果回到 0，面板留着）。
- **`回车`：算得出来的话上屏「算式=结果」**（`5*6` → `5*6=30`，算式里的 `v` 不算）；算不出来就照旧原样上屏。
- 面板里**标点一律按西文进算式**（忽略「中文标点」「符号映射」那些设置）。
- 算式算不出来或者溢出（`1/0`、`9^9^9`、`ln(0)`…）时**候选为空**。

**V 模式没进高级面板时只允许基础运算**：`+` `*` `/`、`%`（求余）、`^`（乘方）、`!`（阶乘）、括号和一元正负号。
函数、虚数单位 `i`、`@` 复数模只在高级数学计算界面里可以用；在 V 模式直接打 `vsin(30)` 不会出结果。
**V 模式里主键盘 `=` / `-` 是翻页键**（和其他模式的翻页一致），所以 V 模式的减法与 `=>` 进制转换都要先进高级界面再用。

支持的运算符与函数（高级界面）：

| 类别 | 写法 |
|---|---|
| 运算符 | `+` `-` `*` `/` `%`（求余）`^`（乘方）`@`（复数模，**只能写在后面**：`(5+6i)@`）`!`（阶乘，写在自然数后面：`5!`） |
| 三角函数 | `sin(30)` / `cos(60)` / `tan(45)` / `cot(45)` 收**角度**；`sinr()` / `cosr()` / `tanr()` / `cotr()` 收**弧度** |
| 反三角 | `asin()` / `acos()` / `atan()`，返回**角度** |
| 对数与开方 | `lg(真数)` / `ln(真数)` / `log(底数,真数)`；`sqrt()` 开平方，负数给虚数单位（`sqrt(-4)` = `2i`） |
| 双曲 | `sinh()` / `cosh()` / `tanh()` |
| 排列组合 | `arrange(样本数,总体数)` / `combine(样本数,总体数)`（`arrange(2,5)` = 20、`combine(2,5)` = 10） |
| 统计 | `avg(数组)` / `vari(数组)` / `sum(数组)`，数组用逗号隔开（`avg(1,2,3)` = 2；`vari` 是总体方差，除以 n；`sum` 是总和） |
| 复数 | 虚数单位是 `i`（`3+4i`、`(1+2i)*(3-i)` = `5+5i`）；**乘号要写出来**：`5*i`、`5*sin(30)` |

几条容易踩的：

- **没有隐式乘法**：`6i`、`2(3+4)`、`2x3` 都不认（`x` 也不当乘号），要写 `6*i`、`2*(3+4)`、`2*3`。
- 虚部不为零时结果写 `a+bi`（`i` / `-i` 不写 1）；实数照旧（整数不带小数点，小数最多十位去尾零）。
- 参数个数不对、名字不认识、定义域外（`asin(2)`、`ln(0)`、`tan(90)`）都算「算不出来」→ 空候选。

### 进制转换（`=>`）

在**高级数学计算界面**（只输入 `v` 后按 `Tab`）输入 `=>` 加一个数，表示把这个数转换成其他进制；前缀只认小写：

| 写法 | 源进制 | `=>0x33ccff` 的结果 |
|---|---|---|
| `0b1010` | 2 进制 | `0o12`、`10`、`0xa` |
| `0o17` | 8 进制 | `0b1111`、`15`、`0xf` |
| `0x33ccff` | 16 进制 | `0b1100111100110011111111`、`0o14746377`、`3394815` |
| `255` | 10 进制 | `0b11111111`、`0o377`、`0xff` |

- 只有 `=>` 开头才是进制转换，普通算式里的 `0x` 不会自动按十六进制解析。
- 输出去掉源进制，按 2 / 8 / 10 / 16 的顺序给其余三种；非十进制带小写前缀，十进制不带前缀。
- 前缀写成 `0X` / `0B` / `0O` 不认；数字不是该进制的合法写法（如 `0b102`）也不出候选。

## 英文候选的大小写

中英混输开着时，输入整段像英文词的字母会给出英文候选，**缺省一律小写**（`github` → `github`）。
当候选窗口里有英文候选时，按 `` ` ``（主键盘 `1` 左侧）可以把**所有**英文候选在三种大小写间轮流切换：全小写 → 全大写 → 首字母大写 → 全小写（`word` → `WORD` → `Word`）。
组句里没有英文候选时，这个键不轮换，仍按普通标点走后。

这也是把 `` ` `` 从「先选高亮候选、剩余拼音补完整体上屏、再上屏标点」那一组标点里排除掉的原因。

## 中英混输

双键拼音下也能按敲的按键匹配英文词，但要不要掺由它自己的「中英文混合输入」开关说了算
（见 [首选项](../settings/preferences.md)，缺省开；关掉一个英文候选都不出）。下面这些是全键拼音的规则。

中文模式下无需切换：

- 整段输入为英文词时给出英文候选，与中文候选按词频和选择次数一起排序，
  `Space` 上屏的仍是中文，按对应序号选英文；没有中文候选时（`github`）英文排第一。
  英文候选缺省一律小写（`windows` → windows）；要 `Windows` / `GitHub` 这种写法，按 `` ` `` 切到首字母大写，或切到 [英文模式](english-mode.md) 原样打。
- 拼音不成立且不少于 3 个字母时补全前缀：`compa` → company / companies / compared。
- 一句拼音末尾接一个英文词时，整句直接包含该词：`woxiangxuehaorust` → 我想学好rust，`wodeid` → 我的ID，`woyongvim` → 我用vim，`yongwindows` → 用Windows。
  拼音行显示 `wo'xiang'xue'hao'rust`，`Space` 上屏整句。该英文词需在词表中（用户自己输入过的也算，见 [英文模式](english-mode.md)）。
  `database` 这类同时可读作拼音的输入，按两种读法的权重排：我的database 与拼音读法都在候选里，谁权重高谁靠前；
  `womenqubeijing` 只给出 我们去北京。`fan`、`to` 这类短词按拼音处理；可纠正为通顺拼音的输入错误（`shiide` → 是的）不视为英文。
  英文词只识别句末，`wozaidebugzhege` 这类位于句中的暂不支持（可先上屏前面的中文，再打英文词）。
- **中英混杂词**（字母 + 汉字）直接按「字母 + 拼音」打：`cpan` → C盘，`bzhan` → B站，`dpan` → D盘，`txu` → T恤，`agu` → A股，`xguang` → X光。
  它们也能进整句：`wozaibzhan` → 我在B站。
- 输入拼音时输入半角标点（`,` `.` `?` 等）会**先把当前高亮的候选选上、把剩余拼音也补完，整段一起上屏，再上屏这个标点**：`bairiyishanjin` 出 白日依山尽 后敲 `,` →
  白日依山尽，（标点按当前模式转全角 / 半角，见 [第一次输入](../getting-started/first-input.md#中文标点)）；高亮候选只吃掉一部分拼音时，剩下的拼音也原样补上，保证标点落得下去。
  `-` `=` 是翻页键；它们上档的 `_` `+` 与拼音分隔符 `'` 不触发上屏。要整段原样输出英文标点（`hello, world?`），切到 [英文模式](english-mode.md)。
