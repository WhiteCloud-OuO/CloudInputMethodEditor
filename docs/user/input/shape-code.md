## 形码输入（五笔86）

在「设置 → 输入 → 输入方案」里选**形码输入**，按键就按字形编码解释，与拼音**互不混合**：
不再走拼音切分与整句转换，`v` / `u` / `i` 也只是普通编码键（要那三种面板用 `Ctrl + Alt + V / U / I`）。
唯一例外是 `z` 开头的 **z 模式**（临时拼音），见下面。

当前内置的方案是**五笔 86**（极点五笔社区词库，单字 + 词组一张表）。打开输入法后照五笔的码打即可：

| 输入 | 候选 |
|---|---|
| `wqvb` | 你好 / 您好 |
| `ggll` | 一 |
| `aaaa` | 工 / 恭恭敬敬 |

- **前缀匹配**：1–4 键都按已经敲的整串查，打 `wq` 会列出所有以 `wq` 开头的字词；
  同一个字在多个编码下命中时只留一条（取权重高的，一级简码通常在前）。
- **单字优先**：单字候选全部排在多字词前面；单字之间仍按码表权重排。打一个前缀时先出单字，
  再出同前缀的词组。
- **一级简码排第一**：只按一个键时，那个键的一级简码一定在第一位，右侧显示 `[①]`
  （`g` → `一 [①]`）。这是固定的 25 个高频字，不会因为别的词权重高被挤走。
- **选词**：空格选高亮项，数字键直接选；候选很多时可以翻页。
- **没选候选回车 / 空格**：把敲的编码原样上屏。
- **退格**：删一位编码，回到上一个前缀。
- **大小写**：Shift / Caps Lock 敲出来的大写也按编码算（匹配用小写），拼音行按敲的样子显示。
- **词库固定**：纯五笔只认方案目录里的码表，权重固定；软件默认词库 / 用户词库 / 第三方词库不参与，
  选了词也不会改变顺序、不会自动造词。

## z 模式：临时拼音 + 五笔反查

**第一个键**按 `z` 就进入 z 模式：`z` 后面打拼音，候选由普通拼音引擎出（默认词库、用户词库、
第三方词库都在这里用），右侧标上它的**五笔完整码**：

```text
zyunduo → 云朵 [fcms]
```

- 反查码取该字 / 词最长的完整码（`的` 给 `rqyy`，不是一级简码 `r`）；码表里没有的词不标。
- 选词时整段 `z...` 一起上屏，不会留下 `z`。
- 只想打普通拼音时用全键拼音方案；z 模式只活在一次组句里。

## 通配符

编码中间 / 末尾的 `z` 是**通配一位**：`fc*s` 命中 `fccs`、`fcis` 这些「以 fc 开头、第四位是 s」的码。
拼音行里 `z` 显示成 `*`。想通配第一位要先打别的键（第一个键 z 是 z 模式）。

## 四码唯一自动上屏 / 第五码顶字

- **四码唯一时自动上屏**（缺省开）：四码打满、候选只剩一个时直接上屏。
- **第五码顶字上屏**（缺省开）：四码打满后再按一个字母，先把当前首选上屏，再把这一个字母当新一段编码。
- **英文混输**（缺省关）：开着时五笔候选后面追加英文词（整段英文词 + 前缀补全，不做拼错纠正）；
  这时第五码顶字会被跳过（第五个字母可能还是英文词的一部分）。

三个开关都在「设置 → 输入 → 输入方案 = 形码输入」那块面板里，记在方案目录的 `use_input_scheme.cfg`。
这三项是**五笔特有**的：切到形码输入下的其他方案（以后的仓颉 / 声笔）时，设置页会换成那个方案自己的设置项，
五笔这三个开关不会生效。

## 换方案 / 换码表

形码方案放在**安装目录**的 `InputSchemes\ShapeCode\` 下，一个方案一个子目录：

```text
InputSchemes\ShapeCode\
  use_input_scheme.cfg      scheme = wubi
  wubi\
    scheme.toml
    table.tsv
    level1.tsv
```

- 换方案：设置页的「形码输入」面板里选，或改 `use_input_scheme.cfg` 的 `scheme = wubi`。
- 换码表：改 `wubi\scheme.toml` 的 `[Shape] Table`，或直接替换 `table.tsv`。
  码表是 UTF-8 的「编码 + 制表符 + 文字 + 制表符 + 权重」，一行一条；`#` 开头是注释。
- 一级简码：`level1.tsv`，一行「键 + 制表符 + 字」。
- 方案支持哪些设置项由 `scheme.toml` 的 `[Options]` 声明（五笔是 `MixtureInput` / `UniqueCommit` /
  `FifthKeyCommit`）；没声明的方案不显示这些开关。
- 改完点「应用方案」（或重启输入法服务）生效。

格式细节见仓库里的 `docs/design/shape-code.md`。
