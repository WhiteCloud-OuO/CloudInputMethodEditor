## 形码输入（五笔86）

在「设置 → 输入 → 输入方案」里选**形码输入**，按键就按字形编码解释，与拼音**互不混合**：
不再走拼音切分与整句转换，`v` / `u` / `i` 也只是普通编码键（要那三种面板用 `Ctrl + Alt + V / U / I`）。

当前内置的方案是**五笔 86**（极点五笔社区词库，单字 + 词组一张表）。打开输入法后照五笔的码打即可：

| 输入 | 候选 |
|---|---|
| `wqvb` | 你好 / 您好 |
| `ggll` | 一 |
| `aaaa` | 工 / 恭恭敬敬 |

- **前缀匹配**：1–4 键都按已经敲的整串查，打 `wq` 会列出所有以 `wq` 开头的字词；
  同一个字在多个编码下命中时只留一条（取权重高的，一级简码通常在前）。
- **选词**：空格选高亮项，数字键直接选；候选很多时可以翻页。
- **没选候选回车 / 空格**：把敲的编码原样上屏。
- **退格**：删一位编码，回到上一个前缀。
- **大小写**：Shift / Caps Lock 敲出来的大写也按编码算（匹配用小写），拼音行按敲的样子显示。
- **暂时没有**：`z` 通配、字根提示、扩展词库、自定义码表；形码方案下本地模型不参与。

## 换方案 / 换码表

形码方案放在**安装目录**的 `InputSchemes\ShapeCode\` 下，一个方案一个子目录：

```text
InputSchemes\ShapeCode\
  use_input_scheme.cfg      scheme = wubi
  wubi\
    scheme.toml
    table.tsv
```

- 换方案：把 `use_input_scheme.cfg` 的 `scheme = wubi` 改成别的子目录名（以后的 `cangjie` / `shengbi`）。
- 换码表：改 `wubi\scheme.toml` 的 `[Shape] Table`，或直接替换 `table.tsv`。
  码表是 UTF-8 的「编码 + 制表符 + 文字 + 制表符 + 权重」，一行一条；`#` 开头是注释。
- 改完在设置页点「应用方案」（或重启输入法服务）生效。

格式细节见仓库里的 `docs/design/shape-code.md`。
