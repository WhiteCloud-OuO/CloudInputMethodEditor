## 两种提示

- **一段拼音切不干净时**（颠倒、输错一个字母）：`nihoama` → 你好吗（相邻两键颠倒）、`nihaomq` → 你好吗（敲到旁边一个键）。
  原样读法的候选一直保留，纠正出来的词按与真敲法的接近程度往后排（颠倒比敲到旁边一个键更靠前）；拼音行按你敲的字母原样显示，不再画删除线。
  这种整段切不干净的情形里不再猜多敲 / 少敲；那段拼音本身能整段对上词或短语时不猜纠正。
- **整段每个音节都合法、整句却讲不通时**：按音节级的多敲 / 少敲试读（`meiganxi` 的 `gan` 少敲一个字母读作 `guan`，出 没关系），
  变体在整句里按概率扣分，原样读法的候选不受影响。
- **末尾落单一个字母时**（多半还没打完）：只按相邻两键颠倒试着找词，`mignt`、`migntia` 就已按 `ming't`、`ming'tia` 给出 明天，继续输入即可。

只有纠正后的词明显更像你要的，它才会排到原样读法前面；合法简拼（`nhao`、`womend`）与整段为英文词的输入（`hello`）都不会被误纠。

## 不需要纠正时

`Enter` 仍将所敲字母原样上屏。

## 记忆习惯性错误

被接受的纠正会记录敲错的那段与想要的音节；选过的词以后按选择次数自然靠前。用 `Backspace` 删除后改选会一并撤销这次记录。
