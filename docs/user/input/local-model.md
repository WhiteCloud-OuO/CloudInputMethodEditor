「设置 → 候选 → 本地模型」有四档，全程离线，不联网、不发送任何内容：

- **关闭**：只用词库与短语匹配，最快、最省电。
- **基本（含章）**：随包的含章·知微整句模型，给整句候选重新排序。
- **增强（知意）**：读光标前文重排候选页，并按音节给整句出字；长句、有上文的输入更明显。模型随安装包提供。
- **混合（含章+知意）**：同时加载两个模型。短语等短输入只走知意；长句让含章重排整句路径、知意再出字和重排候选。效果更稳，但多占约 100 MB 内存、启动多等几秒。

## 怎么生效

敲完一段拼音停一下（不到十分之一秒），模型结果就替换当前页：基本 / 增强 / 混合都会把更合适的整句候选提前，增强和混合还会把前几条里盖住整段输入的候选按前文挑一个挪到第一位。

增强会看光标前面的几十个字；应用不让读上下文时（部分终端、Electron 应用）只看当前应用、当前输入框里最近上屏的字。默认 60 秒没输入就不再算，换应用或换输入框会从头记；时长是配置文件 `[candidate] context_memory_seconds`，填 `0` 表示一直算。

4–8 个音节的短语会优先保留词库里的首选词，避免整句备选把它挤到第一页之外；两三个字的词和更长的句子不受这条保底影响。

模型只影响候选顺序与整句出字，词候选、你选过的词、自动造的词不受它影响；你的习惯仍然优先。

## 什么时候不生效

- 已经翻到后面的页或用方向键移过高亮时，模型的结果不再换掉正在看的这页。
- 密码框里不组句；应用声明为私密的输入框里不读上下文。
- 输入法刚启动的几秒钟模型还在加载，这段时间按词库统计出结果。

## 关闭

「设置 → 候选 → 本地模型」选「关闭」，或配置文件：

```toml
[candidate]
local_model = "off"
```

旧配置里的 `use_local_sentence_organization_model = false` 仍按关闭读取；改完一秒内自动生效。其他档位把 `local_model` 换成 `basic` / `enhanced` / `hybrid`。

## 模型文件

- **基本（含章）**：随包模型在安装目录 `Models\hanzhang-zhiwei-small.qjm`；想换自己的，把 `.qjm` 放进 `%APPDATA%\CloudIME\local_models\`（优先读用户目录），训练仓库直接导出的 `model.safetensors`、`config.json`、`vocab.json` 三个文件放进去也认。
- **增强（知意）**：模型随安装包，位于安装目录 `Models\laya-zhen-long-l12-int8g\`（`laya.int8g.onnx`、`tokenizer.json`、`unified_vocab.json`），运行库是安装目录的 `onnxruntime.dll`，**不需要用户下载**。开发或随包模型缺失时，也可以把同名文件放进 `%APPDATA%\CloudIME\models\zhiyi-onnx\` 作为备用。
- **混合（含章+知意）**：上面两份都要在。缺一份时设置页会提示，并先按找到的那一份工作。
