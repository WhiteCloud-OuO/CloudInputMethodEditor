## 进入英文模式

单击 `Shift`（按下即松开，不与其他键组合）在中 / 英之间切换，任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」，输入法被禁用时显示「禁」。
反向同样有效：点击任务栏的「中 / 英」图标，云朵输入法随之切换（悬浮状态条一并更新）。
中英模式**所有应用共用一份**：在一个应用里切到英文，切到别的应用、新打开的应用也是英文（与搜狗输入法一致）。
右键这个图标弹出菜单：切中文 / 英文、全角标点、打开设置。

`Caps Lock` **只控制大小写**，不改变中 / 英状态：亮着时直接出大写字母（与微软拼音一致），熄灭后回到原来的中 / 英。
亮着时单击 `Shift` 会先取消大写锁定、再切到英文（与微软拼音一致）。
中文模式下 `Shift` + 字母固定进拼音缓冲区参与匹配（大写按小写算，`Cpan` 与 `cpan` 一样能出「C盘」；原样上屏时还原大写），见[按键](../getting-started/keys.md)。

### 中 / 英切换键

切换键固定是**单击 `Shift`**（与微软拼音一致）。误触 `Shift` 切到英文打断了输入时，点任务栏 / 悬浮状态条上的「中」「英」按钮即可切回。
`Ctrl + Space` 不用勾、一直可用：它是 Windows 自带的「输入法 / 非输入法切换」，在云朵输入法里是**禁用 / 启用**——禁用后完全不接管、状态条收起、任务栏图标变「禁」，重新启用回到禁用前的中 / 英。中 / 英仍然只由 `Shift` 切。
装了英文键盘或别的输入法时，Windows 可能改用它直接切到别的输入法，这由系统决定；不想要这条系统热键，到「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」把它改成「未分配」。

## 英文模式是纯直通

切到英文模式后，云朵输入法不再接管输入：字母、数字、标点、空格、回车全部直接交给正在使用的应用，
不出现候选窗口、不组句，与没装输入法时一致。因此终端与代码编辑器里的补全、`Tab`、方向键都不会被输入法占掉。
要英文词的补全与拼错纠正，切回中文模式（见下文「与中文模式的关系」）。

标点缺省半角，需要全角时见上文悬浮状态条。

## 悬浮状态条

任务栏的「中 / 英」不易察觉时，可另开一条**桌面上的悬浮状态条**：它在当前输入法是云朵输入法时一直显示（没有单独的开关）。它是一排图标按钮，点哪个用哪个：

| 按钮 | 显示 | 点击 |
| --- | --- | --- |
| 中 / 英 / 大写锁定 / 禁用 | 中、英，Caps Lock 亮着时是大写锁定图标，输入法被禁用时是「禁」 | 切换中 / 英，与单击切换键相同（禁用时点它回到中文） |
| 中文标点 / 英文标点 | 跟着当前状态换 | 切换全角标点。中英各记一份，缺省中文全角、英文半角，切换模式时随之切换；只记到本次运行，重启后回缺省 |
| 全角 / 半角 | 跟着当前状态换 | 直通给应用的字母、数字与符号是否转全角（中英两模式都算）。只记到本次运行，重启后回缺省（半角） |
| 简 / 繁 | 跟着当前状态换 | 切换繁体输出，与「设置 → 输入」里的「简体中文 / 繁體中文切换」是同一个开关 |
| 设置 | 齿轮 | 打开设置 |
| 工具 / 特殊字符 | | 程序还没做，点了只记日志 |

哪几个按钮显示、从左到右怎么排，写在随包的 `data\icons-arrangement.cfg` 里：一行一个图标，
`button=ch; icon=icons\ch.svg; pos=0`，`pos` 是位置（0 最左，`-1` 表示这个图标不显示），
同一个 `pos` 的几行是同一个按钮的几个状态（中 / 英 / 大写锁定，半角 / 全角，中文标点 / 英文标点，简 / 繁）。
图标是 `data\icons\` 下的 SVG，边长 20 像素、按钮之间与四周留 6 像素。改完存盘，Server 下一次重画状态条时就重读。

按住拖动可移到屏幕任意位置，位置会被记住；大小随系统缩放。
它只在当前输入法为云朵输入法、且输入法没被禁用时显示：切换到微软拼音等其他输入法、或按 `Ctrl + Space` 禁用云朵输入法时收起，切回 / 启用后再次出现；关闭某个应用不影响它。它与任务栏图标并存。
前台是全屏应用（游戏、全屏看视频、演示）时自动收起，退出全屏后回来（这一项可用「设置 → 调试」的「自动隐藏悬浮工具栏」关掉）。也可以在任务栏「中 / 英」图标的右键菜单里切中英、切全角标点或打开设置。

## 记住用户的词

按 `Enter` 原样上屏过的英文词（如 `gist`、`python`）会记入个人词表，下次输入时排在首位。中文模式下选过的英文候选同样记录。

中文模式下 `key`、`id` 这类既像英文词又可读成拼音的输入，中英文候选按词频与你的选择次数一起排序：词频高的靠前，多选几次的那个会往上走；
没有中文候选时英文自然排前面（`github`）。

## 与中文模式的关系

中文模式下整段输入为英文词时同样直接给出英文候选（与中文候选按词频一起排，按对应序号选），
拼音不成立时还会补全前缀（`compa` → company）。
无需切换到英文模式，见 [快捷输入](shortcuts.md)。
