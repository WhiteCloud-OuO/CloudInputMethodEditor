## 模糊音

十二组，一组一勾：`zh/z`、`ch/c`、`sh/s`、`r/l`、`n/l`、`f/h`、`u/ü`、`uo/o`、`an/ang`、`en/eng`、`in/ing`、`wang/huang`。缺省全部关闭。

开启：在「设置 → 输入」勾选。开启 `zh/z` 后输入 `zi` 也出 知 / 之，开启 `f/h` 后输入 `kaiha` 也出 开发，开启 `in/ing` 后 `xin` 也出 星，开启 `wang/huang` 后输入 `wang` 也出 黄。
输入正确的词打折少（模糊命中权重减半），一般排在模糊匹配的词前面。韵母那几组（`uo/o`、`an/ang`、`en/eng`、`in/ing`）与 `wang/huang` 只对完整音节生效。
