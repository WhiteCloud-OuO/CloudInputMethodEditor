## 词库目录

词库都在**程序目录下的 `WordBank\`** 里：

- 随包的 `Dict.db` 中文与英文合在一个 SQLite 存档里，输入法按语言分别加载；它是内置词库，始终加载、不能移除，也不出现在下面的列表里。
- 用户自造词库 `UserWordBank.db` 缺省也在 `WordBank\` 下（位置可在配置文件的 `[word_bank] user_file` 里改，相对安装目录、也可写绝对路径），同样是内置词库、始终加载，不能移除。
- 你导入的第三方词库是 `WordBank\` 下另外的 `.db` 文件；**目录里有的全部加载**，没有启用清单，也不用改配置。列表只显示这些第三方词库。
- 安装包给 `WordBank\` 开了普通用户可写，所以不用管理员权限就能导入 / 删除。

查询按「**用户自造词 → 内置 `Dict.db`（含开启的生僻项）→ 你导入的第三方词库（按导入顺序）**」取词；
同一个词在前面已经查到，后面的词库就不再重复给出这一条，词频也用前面那本的。

## 生僻项条目

- **从词库中查询生僻项条目**（缺省关）：开启后候选与整句才会从词库的生僻字 / 生僻词（方言字、罕见词等）里取词；关闭可加快查询，候选里也不再出现这些冷僻条目。改完输入法一秒内自动生效。

## 导入与移除

「设置 → 词库」列出导入的每一本第三方词库，显示名称、条数、许可证：

- **导入词库…** 只接受现成的 `.db` 词库存档（云朵输入法格式）：复制进 `WordBank\` 并自动加载，同名覆盖。
  选到其它格式（TSV、Rime `.dict.yaml`、`.qj` 等）会给出提示并跳过，不导入。
- **移除** 只把文件挪到 `WordBank\removed\`，不真删；输入法一秒内自动不再加载它。内置词库不能移除。

文件选择窗口支持 Ctrl / Shift 多选，批量导入；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入与移除也会自动更新，无需重启。
