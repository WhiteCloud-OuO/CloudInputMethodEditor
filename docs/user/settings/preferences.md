### 候选

- **使用本地整句模型**：随包的小模型在本机给整句候选重新排序，全程离线；关掉只用词库与短语匹配。
- **候选项排布方向 / 候选项个数**：竖排（一行一个，译文在右侧）或横排（一行排开，只给高亮候选一行译文）；一页 5 到 9 个。
- **联想候选项目上限**（0–4）：候选里「比读法更长的词」最多留几条。打得短（尤其单个字母）时候选里会混进很多这类联想词，把这个调小能让要选的字 / 词留在候选窗口里；0 表示不显示联想候选。缺省 4（最宽松）。
- **三个字体**：拼音串（候选窗口顶部那一行）、候选项、候选项序号，各自点「字体…」选字族与字号（默认微软雅黑 11 / 14 / 9 pt）。没装的字体自动回到系统字体。
- **候选项序号样式**：`1.` / `①` / `Ⅰ` / `❶` / `⑴`。
- **候选框最小宽度**：只在竖排时有效，单位像素（随系统缩放换算）。
- **展示更多候选项**：功能暂未实现，先保留设置项。
- **在下列程序中不显示候选框**：名单里的程序（写 exe 文件名，不区分大小写）输入法完全不接管，按键原样交给应用、候选框与拼音行都不出现——给自带补全列表的编辑器和不希望被挡的游戏用。

### 输入

- **使用简拼**：中文模式下打出 `YD` 就能得到「云朵」，不必打全 `YUNDUO`。关掉只认完整音节（末尾没打完的照常）。
- **模糊音**：见 [模糊音](../input/fuzzy.md)。
- **简体 / 繁體**：选「繁體中文」后候选与上屏文字按 OpenCC 转成繁体（只换字形，不换用语：软件 → 軟件）。引擎内部仍按简体处理：用户词、词频、输入统计与输入日志都记简体。
- **中英文混合输入**：中文模式下也出英文词与英文补全（`KALAOK` 出「卡拉OK」、`hello` 出 hello）。关掉中文模式只按拼音给候选。
- **标点符号全 / 半角**：「跟随中文 / 英文模式」是中文全角、英文半角（缺省），也可以强制全角或强制半角；悬浮状态条上那一格可以在本次运行里再切。
- **中文模式下符号映射**：勾上的项做单键替换，只有 5 个固定项——`/` 出 `、`、小键盘 `/` 出 `÷`、小键盘 `*` 出 `×`、`~` 出 `～`、`·` 出 `` ` ``（`PUNCTUATION_MAPPING_BITS`，配置里是位图 `punctuation_marks_mapping`）。
  两键规则（`~=` 出 `≈`、`!=` 出 `≠` 那几条）真机上总是失效，已连同配置表一起下线；敲下来的字符本来就被内置的全角标点表接走的（`，。？！……`）不受这里影响。
- **符号成对补全**：勾上的左符号会补上右半边，光标停在中间；再敲一次右半边就跳过去。
  补的是**该模式实际打出来的那一对**：中文全角下标点会先转成全角，`(` 补成 `（）`、`[` 补成 `【】`；标点设成半角（或在英文模式里）时 `(` 补成 `()`。
  只对**中文模式**生效——英文模式是纯直通，编辑器自己的括号配对留给编辑器。
  另外 `{` `}` 这类不在内置全角表里的键，不论哪种模式都补 ASCII 的一对（`{}`）。
- **数字后标点使用半角**：`23:06`、`2.36`、`25+9` 里的标点保持半角（缺省开）。
- **中文模式下的 `Shift + 字母`**（固定，没有开关）：按住 `Shift` 敲的字母收进组句缓冲区，匹配时按小写算，所以 `Cpan` 与 `cpan` 一样能出「C盘」；原样上屏（回车 / 没候选）时还原大写。英文模式与英文直输段不受影响；`Caps Lock` 亮着的字母仍是直通（只改大小写）。

### 词库

- **从词库中查询生僻项条目**（缺省关）：开启后候选与整句才会从词库的生僻字 / 生僻词（方言字、罕见词等）里取词；关闭可加快查询，候选里也不再出现这些冷僻条目。改动一秒内生效。
- 内置的 `Dict.db`（随包）与 `UserWordBank.db`（用户自造词库，缺省也在 `WordBank\`）始终加载、不能移除，也不出现在列表里；列表只列导入的第三方词库。
- **导入词库…** 只接受现成的 `.db` 词库存档，复制进 `WordBank\` 并自动加载，选到其它格式会提示并跳过；**移除** 把文件挪到 `WordBank\removed\`，不真删。详见 [词库](dictionaries.md)。

### 短语

用户短语是「敲一串字母 → 整段上屏」的快捷方式（例如 `ww` → 网址、`omw` → On my way!）。

- 页最上方的**启用软件自带短语**（缺省开）决定随包带的常用短语是否参与出候选；关掉只用自己的短语。自带的始终在库里，不占下面的列表。
- 每条有**短语内容**（原样上屏，可含空格与换行）、**候选显示内容**（可留空：留空时候选里显示短语内容，填了则候选里显示它、上屏仍是短语内容）、**触发字母串**（1–32 个小写英文字母）与**候选位置**（1 第一位、2 第二位……）。
- 输入码敲全时短语出现在你指定的候选位置（缺省第二位）；同一位置的多条按保存顺序排，位置超出候选数就排到最后。
- 短语单独存在安装目录的 `Phrases\Phrase.db` 里（目录固定，不能改）。点某一行「编辑」把它填进表单，改完按「保存修改」；「删除」直接去掉那一条。
- 保存后输入法一秒内自动更新，不需要重启。

### 调试

- **输入统计面板**（原「统计」页搬到这里）：今天 / 最近 7 天 / 累计的汉字、中文词、英文词与上屏次数，以及见过 / 上屏过的词数、自哪天起有记录；这些数字只在这台电脑上数、与输入日志无关（算法见 [统计](../learning/statistics.md)）。下面还有「数据与组件」一行行说明：词库目录与主词库、用户短语条数、随包数据（主词库 Dict.db / 语言模型 / 本地整句模型）装没装齐、版本与构建。
- **自动隐藏悬浮工具栏（实验性功能）**：开启（缺省）时，前台是全屏应用（游戏、看视频、演示）会把悬浮工具栏收起来、退出全屏再放出来——开着全屏时不会挡画面。切到别的输入法、云朵输入法被禁用时始终收起，不受这一项影响；关掉后全屏时也不收。
- **打开数据目录 / 打开日志目录 / 打包日志到桌面 / 清空输入日志**：四个按钮排成一行——打开数据目录与日志目录、把日志目录连配置文件打成一个 zip 放到桌面、清空输入日志。
- **软件 GitHub 页面**：打开项目仓库 `github.com/WhiteCloud-OuO/CloudInputMethodEditor`。
- **详细日志**：排查问题时临时打开，会记下敲的拼音与上屏文字。
- **学习输入习惯**：按你的选择调整候选顺序、记新词与敲错纠正；关掉后不再学，已学的仍参与排序。见 [本地整句模型](../input/local-model.md)。
- **记录输入日志**：见 [数据与日志](../help/data-and-logs.md)。

## 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行，页码在行尾。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 直接修改配置文件

全部设置保存在一个配置文件中（`%APPDATA%\CloudIME\config.toml`，可在「调试」页打开数据目录后找到），文件内每一项均附说明。
用户短语已不在配置文件里，改由「短语」页管理（内容 + 候选显示内容 + 输入码 + 候选位置，单独存在安装目录的 `Phrases\Phrase.db`）；配置文件只留 `[phrase] use_default_phrases` 一个开关。
从旧版升级时，旧配置里的键与短语会一次性搬进新格式（旧文件留一份 `config.toml.bak`）。
保存后一秒内生效，无需重新切换输入法。
