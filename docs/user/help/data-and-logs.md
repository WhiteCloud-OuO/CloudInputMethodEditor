云朵输入法不上传任何数据。拼音转换、词库、学习全部在本机完成，没有账号，没有统计上报。

## 检查更新

每天向官网 cloudime.app 读取一次版本列表（一个静态文件），只在本机记录结果，不在界面上提示，也不自动下载、不自动安装。
请求不带账号、设备标识或任何输入内容，只有 HTTP 请求本身带的信息（IP 地址、`cloudime/<版本号>` 的 User-Agent）。
版本列表带数字签名，验证不通过的列表一律忽略。设置里不再有自动检查更新的开关；要关掉，改配置文件的 `[update] check = false`（缺省开）。

## 本机文件

本机文件大多都在「%APPDATA%\CloudIME」（在资源管理器地址栏中直接输入此路径）。

大多是纯文本，可随时打开查看；用户短语的 `Phrase.db` 是 SQLite 数据库，用任意 SQLite 工具也能打开：

| 文件 | 内容 | 是否含输入内容 |
|---|---|---|
| `config.toml` | 配置 | 否 |
| `user.tsv` | 每个词被选择的次数 | 选过的词 |
| `user-words.tsv` | 导入 / 旧版的用户词 | 选过的词 |
| `user-choices.tsv` | 某段拼音下选过的词 | 拼音与选过的词 |
| `user-english.tsv` | 原样上屏过的英文词 | 英文词 |
| `user-typos.tsv` | 被接受的输入错误纠正（输成了什么、本意是什么） | 拼音音节 |
| `user-ngram.tsv` | 词与词之间的接续 | 连续输入过的词 |
| `user-vocab.tsv` | 候选窗口里见过 / 上屏过的词与次数 | 选过的词；私密输入不写入 |
| `usage.tsv` | 按天的汉字 / 词 / 上屏次数，仅数字 | 否 |
| `update.json` | 上次检查更新的时间与查到的新版本 | 否 |
| `input-log.jsonl` | 输入日志：每次上屏的按键、切分、候选、所选序号，以及退格重打、直通的标点、所在应用 | 按键与上屏的文字 |

用户导入的词库、用户自造词库与用户短语不在这个目录：词库和随包词库一起放在程序目录的 `WordBank\` 下（自造词库 `UserWordBank.db` 的位置由配置文件的 `[word_bank] user_file` 决定，缺省也在那里），用户短语单独存在程序目录的 `Phrases\Phrase.db`（内容 · 输入码 · 候选位置，见 [短语](../settings/preferences.md)）；「设置 → 词库」页管理导入的词库，「设置 → 短语」页管理用户短语。

这些文件每次整体替换，即使输入法中途崩溃也不会留下写到一半的文件。

「调试」页的「学习输入习惯」关掉后，`user-*.tsv` 这些学习数据不再更新，已有的仍参与排序；要从头开始就删掉这几个文件。自造词库 `UserWordBank.db` 在程序目录的 `WordBank\` 下，一并删掉即可清空自造词。

## 输入日志

测试版缺省开启。每次上屏在本机记录一行：按键、切分、看到的第一页候选、所选序号、翻了几页、从第一键到上屏用了多久、所在应用的 exe 名。另有几类事件各记一行：组句中退格后重打了不同的键、组句之外直接打出的标点与回车、
切换应用或点到别处、输入法启动。只含通过云朵输入法打出的内容，不含应用中已有的文字，不含密码框与应用声明为私密的输入框中的任何内容，那里也不学习习惯。
它只保存在本机，用于离线回归评测与个人模型，不会自动发送给任何人。

- 关闭：「设置 → 调试」取消勾选「记录输入日志」。
- 清空：同一页的「清空输入日志」。
- 测试期间若愿意将此文件提供给作者，对改进排序有很大帮助；完全自愿。

## 运行日志

「%LOCALAPPDATA%\CloudIME\logs」。引擎（「server.日期.log」）、各应用内的输入法部分（「tsf.日期.log」）与设置程序（「settings.日期.log」）都在这一个目录；
「设置 → 调试」页的「打包日志到桌面」会把整个目录连同配置文件打成一个 zip，反馈时发这个文件即可。

按天分文件，保留 7 天。缺省级别不记录输入内容；仅在「调试」页打开「详细日志」后才逐键记录，用于排查问题，排查完成后请关闭。
