## 卸载

在「设置 → 应用 → 安装的应用」中找到「云朵输入法」并卸载，或使用开始菜单的「CloudIME → 卸载云朵输入法」。
输入法组件被加载在每个用过输入法的程序里（连资源管理器在内），这些程序不重启就删不掉：卸载程序会把它登记到下次重启时删除，并提示重启。

卸载会**一并删除本机数据**：安装目录（含用户短语 `Phrases\Phrase.db`、导入的词库与自造词库）、`%APPDATA%\CloudIME`（设置、学习数据）与 `%LOCALAPPDATA%\CloudIME`（日志），重装不会恢复。
同一台机器上其他 Windows 账户的数据要各自登录后删除。

所有数据均为本机文件，删除后不可恢复，没有云端副本。

## 只清除一部分

- 只清除输入日志：「设置 → 调试 → 清空输入日志」。
- 移除导入的词库：「设置 → 词库 → 移除」只把文件移到程序目录的 `WordBank\removed\`，需彻底删除时自行清理该目录。
