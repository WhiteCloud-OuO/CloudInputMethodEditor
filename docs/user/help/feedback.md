## 反馈时请提供

1. 运行日志：点「设置 → 调试 → 打包日志到桌面」，把生成的 zip 发来即可（含三个进程的日志与配置文件）。也可自取：「%LOCALAPPDATA%\CloudIME\logs」，含引擎、各应用内的输入法部分、设置程序三份日志。
2. 出现问题时所在的应用、输入的内容、预期结果与实际结果。

可复现时，先打开「调试 → 详细日志」再复现一次，日志中即有逐键记录；排查完成后请关闭。

## 常见情况

- **安装后输入法列表中没有云朵输入法**：注销后重新登录。仍然没有，请[提交 issue](https://github.com/WhiteCloud-OuO/CloudInputMethodEditor/issues/new/choose)并附系统版本与安装方式。
- **开始菜单、任务栏搜索框、「设置」中候选窗口被压在下面**：这类系统界面层级高于普通窗口，云朵输入法靠 Windows 的 uiAccess 机制把候选窗口抬到它们之上，
  而系统只对装在 `C:\Program Files`（`%ProgramFiles%`）里的程序启用它，装到其他目录或其他盘会静默失效；想恢复该特性，卸载后重装到默认目录即可。测试版没有正式代码签名，同样会失效，将在签名版中解决；两种情况上屏本身都正常。
- **装了新版输入法后行为没变**：输入法 DLL 会被装进每个程序的进程，**装新版之前就开着的程序要重启**才会用上新代码——在其中切走输入法再切回没有用（模块已经加载进进程了）；资源管理器同理，重启后任务栏搜索框才生效。
  只改设置项不受此影响：保存后一秒内热加载，不用重启应用。
- **按 Ctrl + Space 切到了别的输入法**：Ctrl + Space 是系统的「输入法/非输入法切换」，只装了云朵输入法时它禁用 / 启用云朵输入法（禁用后按键原样交给应用、悬浮状态栏收起），
  装了英文键盘或别的输入法时 Windows 可能改用它切换输入法，这由系统决定。云朵输入法自己的中英切换键固定是单击 Shift；不想要系统这条热键，到「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」把它改成「未分配」。
- **某个应用中无法切换到云朵输入法或输入无反应**：注销后重新登录，或重启该应用。
- **腾讯软件管理、电脑管家等安全软件中无法输入**：这类软件带有进程自我保护（反注入），会阻止第三方输入法加载进它自己的进程；云朵输入法与其他第三方输入法（系统自带的微软拼音除外）在其搜索框内都无法输入、也无法切换中英。这是该软件的安全机制，输入法一侧无法修复。
- **打字时什么都不显示——拼音不出现、候选窗也没有**：多半是后台服务进程 `cloudime-server` 没在跑（崩溃 / 被杀 / 装完没重启）。
  输入法连不上它时会**自己把它拉起来**，下一键即恢复；若仍无反应，从开始菜单的「CloudIME → 云朵 Server」启动它，或注销后重新登录。
- **候选窗口遮挡了终端 / 编辑器自身的补全**：英文模式不给候选（纯直通），切到英文模式即可；要打拼音再单击 Shift 切回来。
- **悬浮状态条不见了**：它只在当前输入法为云朵输入法时显示；确认没有切换到别的输入法，全屏应用时它会自动收起。
- **配置文件改错**：解析失败时沿用上一份能用的配置、不打断输入，运行日志里会记一条「配置热加载解析失败」；按说明改回并保存即可。
- **某个应用中表现异常**（拼音渲染异常、按键被吞、无法读取选区）：请将应用名称与现象反馈给作者；可先在「候选窗口」页更换拼音显示位置作为临时处理。
