<h3 align="center"> 为什么选择做云朵输入法</h3>

　　青简输入法功能确实强大（候选项翻译、支持云联想），但是过于臃肿——并非所有人都需要候选项翻译和云联想。
云朵输入法在青简输入法的基础上几乎推倒重做。
 - 不做双拼输入、五笔输入、仓颉输入等一系列小众输入：不是不愿意支持，而是考虑到太多输入方式可能不利于输入法的维护；
 - 专门针对中文输入优化：用户词库管理+官方词库+第三方词库（需要用户自行配置），即便没有导入第三方词库也能让普通用户能够开箱即用；
 - 所有动作均只在本机上进行，不联网，不窃取用户隐私，代码完全开源；
 - 候选项翻译改为翻译Tip：减小视觉干扰，只做纯粹的输入功能。
