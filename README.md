<h1 align="center">云朵输入法</h1>

本输入法基于 [青简](https://github.com/qingjian-team/qingjian) 修改。

云朵输入法是从青简输入法中独立出来的一个分支，不过同时欢迎进入 [青简官网](https://qingjian.app) 


#### 为什么要做云朵输入法？

青简输入法功能强悍，但是太过臃肿——不是所有用户都需要候选项翻译、不是所有用户都需要配置在线AI模型。

- 只保留全拼功能（用户最多），取消双拼、五笔——不是不愿支持，是贪多嚼不烂；
- 只做Windows上的输入法；
- 不需要青简的候选项翻译，仅保留输入最纯粹的功能；
- 不需要提供云联想功能——保证功能简洁，不联网即可使用；
- 针对中文输入优化——专注词库管理、整句输入。
