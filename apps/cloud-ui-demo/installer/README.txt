Cloud UI Demo
=============

这是 cloud-ui 的独立应用示例，用来验证：
  - 自绘无边框窗口、标题栏（最小化 / 最大化 / 还原 / 关闭）
  - 列表盒（整行显示、滚动、选中）
  - 单行 / 多行文本编辑
  - scrollable_page 控件容器
  - 多窗口
  - 托盘图标与右键菜单（显示窗口 / 隐藏到托盘 / 退出）
  - 窗口蒙版（窗口内容整体变暗，仍可正常点击 / 输入）

直接运行 cloud-ui-demo.exe 即可，不需要安装输入法或其它组件。
程序不写注册表，也不在用户目录写数据；关闭所有窗口即退出。隐藏到托盘后程序仍在后台运行，从托盘菜单退出。

卸载：开始菜单 -> Cloud UI Demo -> 卸载 Cloud UI Demo。
