# 字符数据

这三个 TSV 由旧 VFB 工程（`../legacy/forms/Form2..Form8.frm`，UTF-8，`Caption` 里就是真字符）
一次性导出，编译期用 `include_str!` 嵌进 exe。改字符 / 增删按钮只改这里。

- `pages.tsv`：`页号` + 制表符 + 标签名（1–6，第 7 页「英文花体」在代码里）；
- `glyphs.tsv`：`页号` + `x` + `y` + `字符`。坐标是旧工程里按钮的左上角（28×28 按钮、
  步长 31，分组靠坐标空开），运行时按统一比例缩放、居中；`字符` 一般都是一个字，
  日文页的「浊゛」「半゜」是两个字符；
- `styles.tsv`：`序号` + 52 个十六进制码位（A–Z + a–z），共 14 种花体样式。

页内数量：56 / 111 / 76 / 100 / 110 / 93，合计 546。
