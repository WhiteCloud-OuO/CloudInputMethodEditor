# 随包辅助码表（双键拼音）

两张**首右辅助码**，随安装包发给用户，装到 `{app}\assets\auxiliary\`；程序首次运行会把它们**播种**进
用户可写的方案目录 `InputSchemes\DoubleKeysPinyin\AuxiliaryCodes\`（同名文件已存在就不动它，用户改过的不会被覆盖），
设置页「输入 → 双键拼音 → 辅助码方案」的下拉里就能选到。

- `首右辅助码2.0.tsv`：20896 行，`字\t码`（如 `爱\tPD`、`情\tXH`）—— **新用户的默认辅助码方案**（`DEFAULT_AUXILIARY`）
- `首右plus辅助码.tsv`：8070 行（如 `云\tHI`、`朵\tJM`）

格式与规则见 `docs/design/input-schemes.md` §4：一行一个「字 / 词 + 制表符 + 码」，一个词多个码就写多行；
**码里的字母大小写随便写，读进来统一转成大写**（这里已经是转好的大写）；最长 4 位，格式不对的行读的时候跳过。
