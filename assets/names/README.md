# 取名数据（姓氏 / 名字）

V 模式 `#` 取名用的两份 TSV，安装时原样复制到安装目录 `data\`（Server 启动时读）：

| 文件 | 列 | 说明 |
|---|---|---|
| `姓氏大全.tsv` | 汉字、拼音、排名 | 排名数字越小越靠前；复姓拼音用空格分隔（`ou yang`） |
| `名字大全.tsv` | 汉字、拼音 | 表内顺序就是候选顺序 |

生成 `v#zhangwei` 时先按姓氏拼音匹配（复姓优先、同长按排名），再用剩下的拼音查名字表；
表里没有的同音字（罕见名字用字）再从软件自带词库按词频补在候选末尾。两个字的名可以逐个取：
名的拼音还剩一个音节时，候选里会给「姓 + 第一个音节的字」，选中后剩下的拼音保留。表里没有的
罕见姓氏也退回词库兜底。解析实现在 `crates/cloudime-core/src/name`，候选生成在
`crates/cloudime-core/src/engine/query/name.rs`。

`姓氏大全.tsv` 前 413 条是常见的单姓 / 复姓；后面接着一批罕见姓（`万俟` / `轩辕` / `公孙` /
`隗` / `禤` / `蒯` / `爨` 等），排名继续往后接。它们的排名不会超过前面的常见姓，所以能候选到、
只是排在后面。加新姓氏照这个格式往文件里追加、排名写大一点就行。

这两份文件由用户提供，未附来源许可证；如后续要随安装包分发，请在这里补上来源与许可。
