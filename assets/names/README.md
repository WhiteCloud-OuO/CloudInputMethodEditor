# 取名数据（姓氏 / 名字）

V 模式 `#` 取名用的两份 TSV，安装时原样复制到安装目录 `data\`（Server 启动时读）：

| 文件 | 列 | 说明 |
|---|---|---|
| `姓氏大全.tsv` | 汉字、拼音、排名 | 排名数字越小越靠前；复姓拼音用空格分隔（`ou yang`） |
| `名字大全.tsv` | 汉字、拼音 | 表内顺序就是候选顺序 |

生成 `v#zhangwei` 时先按姓氏拼音匹配（复姓优先、同长按排名），再用剩下的拼音查名字表；
表里没有的罕见姓氏 / 名字字退回软件自带词库按词频匹配。解析实现在
`crates/cloudime-core/src/name`，候选生成在 `crates/cloudime-core/src/engine/query/name.rs`。

这两份文件由用户提供，未附来源许可证；如后续要随安装包分发，请在这里补上来源与许可。
